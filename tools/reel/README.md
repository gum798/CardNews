# 브이로그 릴스 — 모델 없이 만드는 움직임

## 왜 있는가

영상 생성 모델이 24GB 맥에서 안 돈다(H3는 Metal wired 한도 17.76GiB에 걸려 5회 실패).
그런데 우리는 이미 **좋은 스틸을 무료로 매일 뽑고 있다**(Cloudflare FLUX.2-klein-9b).
그 스틸에서 움직임을 만들면 모델이 아예 필요 없다.

실측: 스틸 5장 → 23.2초 1080x1920 릴스, **54초 소요, 피크 RSS 1.36GB**.
Metal 한도의 13분의 1이라 그 벽에 부딪힐 수가 없고, **업무 시간에도 돈다**(로컬 모델이 아니다).
약관 위험 0, 뉴런 0, 계정 0.

## 핵심 원칙

**스틸 5장을 5개 샷으로 만들면 안 된다.** 그러면 슬라이드쇼로 읽힌다.
각 스틸에서 와이드 하나와 얼굴 앵커 펀치인 하나를 뽑아 **9개 샷**으로 만들고,
1.5~3.4초마다 끊는다. 같은 사진에서 잘라낸 펀치인이 「다른 앵글」로 읽힌다.

⚠️ **디졸브를 쓰지 마라.** 같은 얼굴이 나오는 두 컷을 디졸브하면 얼굴이 자기 얼굴 위에
   이중노출돼 즉시 슬라이드쇼 티가 난다. 하드컷 위주로 가고, 마지막 한 번만 디졸브한다.
   (기존 뉴스 릴스 src/video/index.js:85가 정확히 이 실수를 하고 있다 — 0.5초 크로스페이드)

## 기법

- **dolly** — 강체 레이어 2.5D 패럴랙스. tools/matte로 인물을 오려 통째로 이동시키고
  배경만 깊이 변위시킨다. 실루엣이 안 뭉개지므로 **얼굴이 있는 컷은 무조건 이걸 쓴다.**
- **drift** — 변위장 방식. 싸고 부드럽지만 깊이 경계가 고무처럼 늘어난다. 얼굴 없을 때만.
- **push / pull** — 켄번스 인/아웃, 이징 적용.
- **punch** — 같은 스틸에서 얼굴을 앵커로 잡은 타이트 컷어웨이.

**핸드헬드**: 축마다 서로 소인 사인파 2개를 겹친다. 하나만 쓰면 주기가 규칙적이라
눈이 2초 안에 메트로놈을 잡아낸다.
