# 영상 분석: "AI에게 인스타그램 운영을 시키면 팔로워를 몇 명 모을까?"

- **채널**: 이영배
- **URL**: https://youtu.be/46GrAocDqR0
- **길이**: 19:46 | **업로드**: 2026-07-16 | **조회수**: 약 46,000 (분석 시점)
- **내용**: Claude Code로 인스타 카드뉴스 자동화 시스템을 만들어 10일간 3개 계정 운영 실험

## 1. 영상 속 시스템 구조

```
[RSS 수집] → [AI 후보 선별] → [텔레그램 보고] → [운영자 승인 버튼]
    → [카드뉴스 생성 (템플릿 기반)] → [릴스 버전 생성 (슬라이드 영상 + 음악)]
    → [인스타그램 업로드 (수동 → 반자동 → 완전 자동)]
```

1. **수집**: 해외 이슈/뉴스 사이트에서 매일 RSS로 소식 수집
2. **선별**: AI가 괜찮은 후보 1차 선별 → 텔레그램으로 전송
3. **승인**: 운영자가 텔레그램에서 확인/발행 버튼 클릭 (최종 검수 역할만)
4. **제작**: 미리 만든 디자인 템플릿에 AI가 내용을 끼워넣어 카드뉴스 생성
   - 요소 구성/배치는 사람이 지시, 다듬기는 AI
   - 배경 사진은 AI 이미지 생성
5. **릴스 변환**: 같은 카드를 릴스 비율로 슬라이드 나열한 영상 제작
6. **업로드**: Meta for Developers에서 인스타그램 API 키 발급 → 자동 게시
   - 초기 문제: API 자동 업로드 시 음악 삽입 불가
   - 해결: 저작권 무료 음악을 미리 확보 → AI가 영상에 입혀서 업로드

## 2. 운영 방식 진화 (3개 계정)

| 계정 | 주제 | 방식 | 결과 |
|------|------|------|------|
| 배슈매거진 | 해외 신기한 이슈 | 수동 업로드 | 팔로워 0, 평균 조회수 110~120 → **운영 중단** |
| 뉴스여기스 | 오늘의 뉴스 | 반자동 → 풀자동 | 팔로워 15, 누적 조회수 14.5만, 릴스 최고 10.2만 |
| AI말도안돼 | AI 뉴스 | 완전 자동 (발행 버튼만) | 4일간 팔로워 1, 총 1,900회 |

- 시스템 초기 제작: 2~3시간. 이후 하루 10분 미만 운영 (버튼 클릭만)
- 일주일에 게시물 35~42개 업로드 (하루 3~4개)

## 3. 핵심 교훈 (영상에서 검증된 것)

1. **카드뉴스(피드 게시물)는 주로 팔로워에게만 노출** — 팔로워 0명이면 조회수 0.
   릴스는 비팔로워에게 노출 → **같은 카드뉴스도 릴스 형태로 올리면 조회수 급증** (하루 만에 2.5만 → 최고 10.2만)
2. **콘텐츠 주제가 성패 좌우** — 같은 시스템·같은 디자인이어도 "뉴스" > "해외 이슈" > "AI 뉴스"
3. **프로필 세팅이 팔로우 전환 좌우** (6만 팔로워 전문가 진단):
   - 4줄 구조: ① 슬로건 ② 이력/사회적 증거 ③ 제공 가치 ④ 팔로우 CTA ("팔로우하면 매일 뉴스 5개")
   - 조회수 10만이면 팔로워 1,000명은 모였어야 정상 → 전환 병목은 프로필
4. **성장 루틴**: 하루 릴스 1 + 카드뉴스 1 + 스토리 4. 해외 바이럴 포맷을 내 주제에 이식
5. **AI 개선 루프 유효**: 계정 현황을 Claude Code에 주고 개선안 요청 → 프로필 문구 변경, 릴스 첫 화면 시간 단축, 공유/저장 유도 등 반영
6. **디자인 품질**: 현직 디자이너 평가 — "AI인지 티 안 남, 깔끔함". 사람이 포토샵으로 만들면 카드 3~4장에 약 30분, AI는 약 2분
7. **결론**: "자동화는 정말 편하지만, 딱 편한 만큼의 결과물이 나온다" — 카드뉴스만으로는 성장 한계, 릴스 병행 필수
